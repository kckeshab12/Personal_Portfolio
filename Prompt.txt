🧪 Bonus Tip: Make VS Code Terminal Use CMD by Default
If you'd rather not deal with PowerShell at all:

In VS Code, press Ctrl + Shift + P

Search: Terminal: Select Default Profile

Choose: Command Prompt

Open a new terminal (Ctrl + backtick) → it will now use CMD
